# workandsail

Proyecto que empieza desde cero. Repositorio remoto: https://github.com/jacobo710/workandsail

## Regla principal: todo se guarda en este repositorio

El usuario quiere que **absolutamente todo lo que se hable** con Claude quede guardado aquí.

En cada turno de conversación:

1. Añade al registro del día, `conversaciones/AAAA-MM-DD.md`, lo que se habló: la petición del usuario, las decisiones tomadas, lo que se hizo y lo que quedó pendiente. Si el archivo del día no existe, créalo.
2. Si se tomó una decisión importante sobre el proyecto (objetivo, tecnología, diseño, alcance), anótala también en `docs/decisiones.md`.
3. Haz commit de los cambios y `push` a `origin main` al terminar el turno.

Idioma: español.

Git está en `C:\Program Files\Git\cmd\git.exe` (puede no estar en el PATH de la shell).
